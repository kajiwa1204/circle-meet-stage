# HTML & CSS 入門ハンズオン（2026-08-09）

HTMLとCSSの基礎を教えて、プロフィールサイトを作り GitHub Pages で公開するまでがゴール。

## starter / example

同じプロフィールサイトの「作りかけ」と「完成形」。どちらも `index.html` / `style.css` / `images/` の3点構成。

| | 役割 |
|---|---|
| `starter/` | **参加者に配るテンプレート。** HTMLを穴埋めにしてあり、`TODO` コメント（9箇所）に沿って自分の内容へ書き換えて完成させる |
| `example/` | **完成例。** スライドで解説しているコードの実物。答え合わせや、先に完成イメージを見せる用 |

`style.css` と `images/avatar.svg` は両者で同一。**CSSは完成した状態で配る**ので、
参加者はHTMLを書き換えるだけで見た目の整ったページになる。
CSSはPart 3で読み解きながら、各自で色などを変えていく流れ。
