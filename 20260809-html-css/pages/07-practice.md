# 余裕がある人へ：発展課題

<div class="grid grid-cols-2 gap-6 mt-6 text-sm">

<div>

### デザインを盛る

- `box-shadow` でカードに影をつける
- `transition: 0.3s;` で hover を滑らかに
- Google Fonts で好きなフォントを使う
- `linear-gradient` で背景にグラデーション

### 中身を増やす

- 2ページ目（`works.html`）を作ってリンクする
- 表（`table`）で時間割を載せる
- 問い合わせフォーム（`form`）を置く

</div>

<div>

### 調べる力をつける

- **MDN Web Docs** — 一次情報。「mdn flexbox」で検索
- **Chrome 検証ツール** — 右クリック → 検証。
  その場でCSSを書き換えて試せる

<div class="mt-4 text-sm opacity-70">
「やりたいこと + css」で検索する癖をつけると早いです。<br>
例：「文字 中央 css」「影 つける css」<br><br>
プロも毎日ググっています。
